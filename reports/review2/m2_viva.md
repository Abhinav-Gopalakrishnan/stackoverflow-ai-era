# Rishiikesh: Review 2 viva

- Why no code in tone/topics? Code words and identifiers can be mistaken for emotion; topics should describe prose. Code is measured separately for complexity.
- Why overrides? Technical words like fatal/kill/error should not count as negative human emotion by themselves.
- Why weights? Before 2025 sampled questions represent unequal amounts of the population, so weighted summaries preserve the sampling design.
- What is kappa? Agreement between two independent human raters beyond chance; it remains unavailable until both raters label the sample.
- Why bootstrap? Resampling questions with their existing weights estimates uncertainty in medians/share changes.
- Validation status: VADER against M3's single-human reference: accuracy 36.0%, macro-F1 0.344. Human–AI kappa 0.214; this is not two-human validation.
- Can AI count as a human rater? No. The assisted comparison is disclosed and the original two-human requirement is not claimed.
- Topic naming: ten AI proposals include a mixed numerical-table topic; the comparison is qualitative, not blind human agreement.
